# Overview

This package contains all code necessary to replicate the Monte Carlo 
simulations and empirical application presented in "The moment is here: 
a generalised class of estimators for fuzzy regression discontinuity designs".
To produce all outputs in the paper, simply run `master.R` (recommended from
RStudio, otherwise explicitly set your working directory by uncommenting
`setwd()` on line 16 of `master.R`).

# Data 

All simulation data are generated by the code provided in this replication package.
To ensure reproducibility, seeds are set in the following way within the parallel loop:

```r
param_id <- dgp * 10000 + running_variable * 1000 + setup * 100 +
  round(p1 * 10) + (n %/% 100)
iter_seed <- 1234 + param_id * NSIM + i
set.seed(iter_seed)
iter_seeds[i] <- iter_seed
```

This architecture ensures that:

- Results from any parameter configuration can be exactly replicated without 
  running the entire grid
- Each simulation draw has a unique, deterministic seed
- Parallel processing does not affect reproducibility

### Important Notes

- **Exact replication requires:** `NSIM = 10000` (as used in the paper)
- **Changing NSIM:** Modifying `NSIM` in `config.R` will change the seed sequence and produce 
  different (but statistically equivalent) results.

### Secondary Data (Empirical Application):

- Angrist and Lavy (1999) class-size effects on test scores data
- Reference: Angrist, J. D., & Lavy, V. (1999). Using Maimonides' rule to estimate the effect of class size on scholastic achievement. The Quarterly journal of economics, 114(2), 533-575.
- Available at: https://economics.mit.edu/people/faculty/josh-angrist/angrist-data-archive
- Data come cleaned, no restrictions on access

# Computational Requirements

## Software Requirements

**R (version 4.3.1 or higher)**

Required R packages (automatically installed by `master.R` if missing):

- `dplyr` - Data manipulation
- `haven` - Reading Stata .dta files
- `rdrobust` - RD robust estimation/inference procedures
- `RDHonest` - Honest confidence intervals for RD designs
- `parallel` - Parallel computing support
- `doParallel` - Parallel backend for foreach
- `foreach` - Parallel loop construct
- `expm` - Matrix exponential and related functions

**Python (version 3.8 or higher)**

Required Python packages (automatically installed by `master.R` if missing):

- `pandas` (>= 2.0.0) - Data manipulation and CSV processing

## Hardware Requirements

- **Memory:** Minimum 16GB RAM recommended for full simulations
- **Storage:** Approximately 2GB disk space required
- **Processor:** Multi-core processor recommended (simulations use parallel processing)
- **Operating System:** Windows 10/11, macOS 10.14+, or Linux

## Runtime

The full replication package took approximately 10 hours to run locally on a 24-core machine
with 32GB RAM, with 23 cores used in parallel for Monte Carlo simulations (implemented via fork / mclapply), which dominated runtime.

**Note:** Runtime can be significantly reduced by:

  - Modifying `NSIM` and `NSIM_FIGURES` in `config.R` (at the cost of Monte Carlo accuracy)
  - Modifying `GRID_POINTS` for bias-aware AR confidence intervals in the application
  - Using more CPU cores (modify `NUM_CORES` in `config.R`)
  - Reducing the size of the (`DGPS`, `RUNNING_VARIABLES`, `SETUPS`, `P1_VALUES`, `NS`, `ERROR_DISTRIBUTIONS`) grid

## Dependencies Installation

All required R and Python packages are automatically installed when running `master.R`. 
Manual installation is not necessary but can be done as follows:

**R packages:**
```r

    "foreach", "triangle","expm")
)
```

**Python packages:**
